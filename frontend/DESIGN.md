# 탈:정왕 디자인 시스템

> 방향은 모던 미니멀 유틸리티, 정제된 teal accent, SUIT 폰트, 라이트 퍼스트에 다크 동급이다.
> 모든 hex 는 Radix Colors 공식 소스(`src/light.ts`, `src/dark.ts`)에서 검증했다.

## 0. 이 문서를 읽는 법

표에는 두 종류의 값이 섞여 있다.

| 표시 | 뜻 |
|---|---|
| (없음) | 코드에 그대로 들어 있는 현재 값이다. `src/index.css` 또는 `tailwind.config.js` 와 일치한다. |
| `목표` | 아직 코드가 이 값이 아니다. §9 부채 대장에 이유와 남은 작업을 적었다. |

2026-09 이전 판은 목표를 현재형으로 적어 두었다. radius 5개 고정, 그림자 2단계,
굵기 800과 900 미사용, 도착 카드 단일화 네 가지가 모두 사실이 아니었고, 그 문서를 믿고
쓴 코드가 실제 값과 어긋났다. 그래서 이번 판부터 두 축을 분리해 적는다.
현재 값을 바꾸려면 코드를 먼저 바꾸고 이 문서를 따라 고친다. 반대 순서로 하지 않는다.

| 개념 | 값 | 하는 일 | 출처 |

임박 90초는 `utils/eta.js` 가 이미 정본으로 정해 둔 값이다.
이전 판 문서는 §2 에서 3분, §8.1 에서 5분이라고 적어 두 값이 충돌했고 둘 다 코드와 달랐다.
문서를 코드에 맞춘다.

분 단위 값만 가진 화면(지도 마커, 시간표 목록의 시간 열)은 `isImminentMinutes` 를 쓴다.
같은 임계값을 분으로 내린 것이며, 각자 "3분 이하"·"1분 이하"로 다시 재지 않는다.
그렇게 재던 시절 같은 목록의 같은 시간 열에서 버스는 90초에, 지하철은 60초에 강조로 바뀌었다.

숫자를 텍스트로 갈아 끼우지 않는다. 임박은 숫자 색으로 표현한다(§6.1).
시간표에서 계산한 값에는 임박 표기를 쓰지 않는다. 예보가 아니라 예정이다.

### 2.5 접근성

색은 보조 신호다. 실시간, 임박, 지연, stale 은 항상 아이콘 또는 텍스트 라벨을 1차 신호로 동반한다.
색만으로 구분하지 않는다. 본문 대비는 WCAG 2.2 AA(4.5:1) 를 최소로 지키고,
accent 텍스트는 `--tj-accent-ink` 를 쓴다.

### 2.6 상태 낱말은 축마다 한 세트다

혼잡도는 `여유 / 보통 / 혼잡 / 매우 혼잡` 하나다(`utils/crowdingLevel.js` `CROWDING_LABELS`).
축이 둘이지만 낱말은 하나다. 비율 축(과거 통계, `labelFromRatio`)과 등급 축(실시간 단일
차량, `labelFromLevel`)이 서로 다른 낱말을 쓰면 한 컴포넌트 안에서 색은 등급으로, 글자는
비율로 정해져 `매우 혼잡` 이 `보통` 의 노란색으로 나온다. 색도 글자와 같은 축에서
뽑는다(`levelFromRatio`).

낱말을 평균에서 뽑지 않는다. 평균은 하한이 1이라 값 1인 버스와 3인 버스가 반씩이면
2(`보통`)가 되는데, 그 2는 실제로 존재한 어떤 버스도 설명하지 못한다. 기준은 혼잡 이상
비율이다.

도로 소통은 `원활 / 서행 / 정체` 하나다(`utils/trafficLevel.js`). 판정 입력은 속도
하나이고 지도도 카드도 같은 함수를 쓴다. 백엔드가 보내는 `congestion` 코드는 임계값이
달라 표시에 쓰지 않는다. §9 참조.


## 3. 타이포그래피

폰트는 SUIT Variable 단일이다. 숫자 강조는 `tabular-nums` 를 쓴다.

모든 fontSize 토큰은 `calc(Npx * var(--tj-font-scale, 1))` 형태다.
설정의 글자 크기 슬라이더가 `--tj-font-scale` 하나만 바꾸면 전 화면에 반영된다.
이 스케일 밖으로 나가는 값(인라인 `fontSize` 숫자, `text-[Npx]`, cssText 안의 `font-size`)은
슬라이더를 무시하므로 쓰지 않는다.

### 3.2 목표 스케일

`목표` 8토큰이다. 위계는 크기와 색과 자간으로 먼저 만들고 굵기는 마지막 보조로 쓴다.

| 토큰 | px / line-height / weight | 용도 |
|---|---|---|
| `caption` | 13 / 17 / 400 | 타임스탬프, 부가 |
| `body-sm` | 14 / 19 / 400 | 리스트 보조 |
| `body` | 16 / 23 / 400 | 기본 본문 |
| `label` | 15 / 21 / 500 | 버튼, 탭 라벨 |
| `head-sm` | 17 / 23 / 600 | 카드 타이틀 |
| `head` | 21 / 29 / 600 | 섹션 타이틀 |
| `num-lg` | 29 / 33 / 600 + tnum | 도착 숫자 |
| `num-xl` | 37 / 41 / 700 + tnum | 화면당 1곳 한정 hero 숫자 |

굵기는 400 본문, 500 라벨, 600 헤딩과 버튼과 숫자, 700 은 화면당 1곳만 쓴다. 800 과 900 은 쓰지 않는다.

현재 `head` 는 문서 목표(21 / 600)와 코드(17 / 700)가 서로 다른 것을 가리킨다.
목표 스케일로 옮길 때 이름 충돌부터 정리해야 한다.

### 3.3 자간과 행간

본문 `-0.01em`, 숫자와 헤딩 `-0.02em` 이다. SUIT 가 타이트해서 음수 자간을 쓴다.
`.tnum` 유틸(`font-variant-numeric: tabular-nums`)은 도착 시간과 시계에만 붙인다.

현재 `tracking-*` 적용이 107건에 14종이다. 같은 값을 `tracking-[-0.01em]` 과
`tracking-[-.01em]` 두 표기로 쓰고, 한글에 양수 자간(`tracking-wide`, `wider`, `widest`)을
21건 쓴다. `목표` 는 위 두 값만이다.

한글에 양수 자간은 로마자 라벨용 값이라 쓰지 않는다. 예외는 없다.

## 4. Shape, Elevation, Motion

### 4.1 Radius

컴포넌트별로 의도적으로 차등을 둔다. 전부 같은 값이면 AI 가 만든 균질감이 난다.

현재 `tailwind.config.js` 의 borderRadius 키는 12개이고 값은 7종이다.

| 키 | 값 | 용도 |
|---|---|---|
| `badge` | 8px | 노선번호 배지 |
| `chip` | 8px | `badge` 별칭 |
| `button` | 10px | 버튼 |
| `input` | 10px | 인풋 |
| `mini` | 10px | `button` 별칭 |
| `btn` | 10px | `button` 별칭 |
| `card-pc` | 14px | PC 카드 |
| `tile` | 16px | 카드 안 타일 |
| `card` | 20px | 카드 |
| `card-lg` | 20px | `card` 별칭 |

| `pill` | 999px | 칩, 상태 |

10px 에 이름이 넷, 8px 에 둘, 20px 에 둘이다.
`목표` 는 별칭 여섯을 없애고 `badge` 8, `button` 10, `card-pc` 14, `tile` 16, `card` 20,
`sheet` 26, `pill` 999 여섯 값만 남기는 것이다.

`rounded-[Npx]` 임의값은 쓰지 않는다. 현재 `rounded-[3px]` 두 곳, `rounded-sm`(2px) 세 곳,
`rounded-lg`(8px) 한 곳, 인라인 `borderRadius` 19곳(값 7종)이 남아 있다.

### 4.2 Shadow

현재 boxShadow 키는 8개다.

| 키 | 값 | 상태 |
|---|---|---|
| `sh-card` | `0 1px 2px rgba(26,33,30,.04), 0 3px 12px rgba(26,33,30,.07)` | 현행 |
| `sh-lift` | `0 2px 6px rgba(26,33,30,.06), 0 12px 32px rgba(26,33,30,.12)` | 현행 |
| `sh-pop` | `0 8px 24px rgba(0,0,0,.12)` | 현행 |
| `card` | `0 2px 8px rgba(0,0,0,0.04)` | 레거시 |
| `card-md` | `0 2px 10px rgba(0,0,0,0.06)` | 레거시 |
| `pill` | `0 4px 14px rgba(0,0,0,0.10)` | 레거시 |
| `dock` | `0 6px 24px rgba(0,0,0,0.25)` | 모바일 독 전용 |
| `map` | `0 2px 10px rgba(0,0,0,0.08)` | 지도 컨트롤 전용 |

`목표` 는 `sh-card`, `sh-pop` 두 단계다. 레거시 넷은 제거 대상이고,
`dock` 과 `map` 은 용도가 좁아 남길지 판단이 필요하다.

다크에서는 그림자 대신 `--tj-line` 으로 표면을 구분한다.
보더와 그림자를 동시에 쓰지 않는다. 현재 동시 사용이 27곳 있다.

### 4.3 Motion

순수 CSS 다. 거의 모든 상호작용에 모션을 두되 duration 은 타이트하게 잡는다.

이징은 `--e-out: cubic-bezier(0.32,0.72,0,1)`(진입, 시트),
`--e-spring: cubic-bezier(0.5,1.35,0.5,1)`(press, pop, knob),
`--e-inout: cubic-bezier(0.65,0,0.35,1)`(크로스페이드) 셋이다.

duration 은 실제로 적용되는 `index.css` 값을 기준으로 한다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--dur-motion-press` | 90ms | press |
| `--dur-motion-base` | 110ms | 토글, 세그먼트, 색 |
| `--dur-motion-enter` | 120ms | 카드, 리스트 진입 |
| `--dur-motion-sheet` | 140ms | 바텀시트 |

`tailwind.config.js` 에는 같은 이름으로 `base 200ms`, `enter 300ms`, `motionSheet 440ms` 가
따로 정의돼 있다. 두 값이 공존하고 화면에 적용되는 것은 `index.css` 쪽이다. 제거 대상이다.

패턴은 press(scale 0.94 spring), 토글 knob 슬라이드, 세그먼트 인디케이터 슬라이드,
별과 체크 pop, 카드 진입(fade 와 상승과 미세 스케일), 리스트 스태거 60ms,
바텀시트 슬라이드업, 도착 숫자 롤, 탭 크로스페이드, 실시간 펄스, 스켈레톤 시머다.

목적 없는 fade-in 을 남발하지 않는다. 오버슈트는 미세하게 준다.
`prefers-reduced-motion: reduce` 에서는 관련 토큰을 0ms 로 낮춘다.

## 5. 네거티브 룰

- 그라디언트를 남발하지 않는다. 브랜드 tint 배경과 날씨 히어로만 예외다. 메시 그라디언트와 네온 글로우를 쓰지 않는다.
- 그림자 3단계 이상을 쓰지 않는다. 보더와 그림자를 동시에 쓰지 않는다.
- teal accent 는 손전등이다. 진행중, CTA, 현재시각, 실시간에만 쓴다. 대면적 teal 배경을 쓰지 않는다.
- primitive hex 를 인라인으로 직접 쓰지 않는다. semantic 토큰만 참조한다.
- radius, weight, size 는 위 토큰 밖 임의값을 쓰지 않는다.
- 12px 미만 폰트를 쓰지 않는다. `*.token.test` 가 `src/**` 전역에서 강제한다.
- UI 렌더 문자열에 em dash 와 en dash 를 쓰지 않는다. 구분은 `·` 를 쓰고, 침묵 대신 낱말을 쓴다.
- 침묵 기호를 값 자리에 쓰지 않는다. `-`, `--`, `--:--`, `·` 를 도착 시각 자리에 넣지 않는다.
- 개발자 용어를 UI 에 노출하지 않는다. `표본 n건`, `GBIS`, `p10`, `p90`, `초 전 폴링`, `ROUTES` 가 해당한다. 필요하면 툴팁으로 넘긴다.
- 히트맵과 차트는 뷰포트 안에서 완결한다. 가로 스크롤을 두지 않는다. 24칸이 안 들어가면 버킷을 줄인다(2시간 12칸).
- 위치 정보가 없으면 거리 표기를 숨긴다. 지어낸 상수로 도보 시간을 계산해 여유 판정을 만들지 않는다.
- 이모지를 UI 문자열에 쓰지 않는다. 상태는 텍스트와 의미색으로 표현한다.

## 6. 컴포넌트 규격

### 6.1 TransitCard — 도착 카드 단일 규격 (`components/ui/TransitCard.jsx`)

버스와 지하철과 셔틀의 모든 도착 카드는 이 컴포넌트 하나만 쓴다.
해부도는 `[노선 타일][본문: 행선지 15px bold + 칩 행][ETA 열: 22px tnum + 보조 13px]` 로 고정한다.
크기 변형은 둘이다. `md` 는 목록 행이고 `lg` 는 화면에 한 장만 놓이는 카드다.
`lg` 는 타일 64px, 제목 17px, ETA 28px 이며 보조 줄을 하나 더 쓸 수 있다.

- 제목은 행선지다. 출발 정류장은 리스트 헤더에서 한 번만 말한다.
- 행선지를 말줄임하지 않는다. 최대 2줄이고, 좁아지면 칩이 먼저 숨는다.
- 칩 순서는 실시간, 혼잡, 경유 셋으로 고정한다. 카드마다 배치가 달라지지 않는다.
- 임박은 `--tj-imminent` 숫자색 하나로만 표현한다. 카드 보더 강조, 배경 틴트, halo 펄스, 숫자를 텍스트로 대체하는 것을 전부 금지한다.
- 미운행과 정보 없음은 mute 계열이며 초록을 쓰지 않는다. 반드시 대안 정보를 말한다. 예를 들어 `주말 미운행 · 월 첫차 06:30`, `시간표 기준 15:20 출발` 이다.

해부도를 그리는 곳은 이 파일 하나다. `dashboard/ArrivalRow` 는 지웠고,
`bus/BusArrivalCard`, `bus/ArrivalEtaCard`, `schedule/ScheduleSection` 은 데이터를 이
컴포넌트의 프롭으로 옮기는 일만 한다. `bus/BusEtaCard` 는 목록 행이 아니라 상세 시트
상단의 안내 패널이라 카드 해부도를 쓰지 않지만, 도착 숫자는 같은 `text-eta` 규격이다.

`SkeletonArrivalCard`(`components/common/Skeleton.jsx`)가 이 카드의 셸과 그리드를
그대로 흉내낸다. 셸을 바꾸면 그쪽도 같이 바꿔야 로딩에서 결과로 넘어갈 때 레이아웃이
튀지 않는다. `Skeleton.test.jsx` 가 두 클래스 집합을 대조한다.

### 6.2 SegmentedControl — 토글 단일 규격 (`components/ui/SegmentedControl.jsx`)

등교와 하교 같은 상호배타 토글은 전부 이것을 쓴다.
선택 상태는 `--tj-pill-active-*`(라이트는 잉크 필, 다크는 잉크 반전)다. teal 선택 배경을 쓰지 않는다.
정류장 필터 칩(민트 틴트 선택)과 시각 언어를 분리하고, 같은 행에 두 그룹을 두지 않는다.

터치 영역은 `md` 와 `sm` 모두 44px 다. `sm` 이 바꾸는 것은 높이가 아니라 폭 거동
(컨테이너를 채우지 않고 콘텐츠만큼만)과 글자 크기다. 카드 위에 얹히는 자리라도
손가락 크기는 협상하지 않는다.

구현체는 이 파일 하나다. `SegmentedControl.test.jsx` 가 `src` 전체를 훑어
`role="tablist"` 와 슬라이딩 인디케이터를 함께 가진 다른 파일이 있으면 실패한다.

### 6.3 DataBadge — 정보 출처 단일 규격 (`components/ui/DataBadge.jsx`)

실시간과 시간표와 stale 은 이 배지 하나로 표시한다.

- 실시간 배지는 accent tint 에 펄스 점을 붙인다. 펄스는 실제 실시간 값에만 붙인다. 시간표에서 계산한 값에 붙이지 않는다.
- 시간표 배지는 mute 텍스트다. 색 배지를 쓰지 않는다.
- 카드 하나에 실시간과 시간표 배지를 동시에 띄우지 않는다. 그 카드가 지금 보여주는 값의 출처 하나만 말한다.
- 값이 어느 정류장 기준인지는 숫자 아래 보조행에 적는다.

`목표` 다. 현재 같은 개념을 `StatusChip`, 인라인 span 두 종류, `DataBadge` 넷으로 그린다.

StatusChip 의 `kind` 는 선언된 값만 쓴다. 선언에 없는 값은 폴백을 타고 다른 뜻의 칩이 된다.
`StatusChip.test.jsx` 가 `src` 전역의 `kind=` 사용처를 훑어 이를 막는다.

### 6.4 empty state 철칙

왜 없는지와 지금 뭘 할 수 있는지를 반드시 말한다.
침묵 대시와 `추후 업데이트 예정` 류를 쓰지 않는다.
데이터가 있으면(학기 시간표 등) 반드시 이어 준다. CTA 는 문장이 아니라 버튼으로 만든다.

오류를 빈 상태로 위장하지 않는다. `error` 를 읽지 않고 빈 배열만 보고 빈 상태를 그리면,
서버 장애와 오늘 운행 없음이 같은 화면이 된다. 둘은 사용자가 할 일이 다르다.

`정보 없음` 을 뜻하는 문자열이 현재 아홉 가지다. 하나로 모은다.

### 6.5 즐겨찾기 favKey 스키마 (`utils/favKey.js`)

`{mode}:{id}:{direction}` 이다. 예를 들어 `bus:3:하교`, `subway:suin:up`, `shuttle:main:등교` 다.
저장(`favorites.keys`)과 필터와 표시가 전부 이 키 하나를 읽는다.
레거시 값은 `matchesLegacy` 로만 허용한다.

이 스키마를 읽지 않는 소비처가 지금 셋이다. 푸시 구독(`SettingsPage`), 독 팝오버(`favCode.js`),
PC 사이드바다. 셋 다 옛 `favorites.routes` 만 읽어서, 시간표에서 누른 별이 조용히 빠진다.

## 7. 검사 강제 범위

`src/tokenRules.test.js` 가 전역으로 강제하는 것은 다섯 가지다.

1. `text|bg|border|ring|divide-(slate|gray)-N` 클래스 금지
2. `text-[Npx]` 임의값 금지
3. tailwind fontSize 키 12px 미만 금지
4. 주석 밖 em dash 금지
5. 인라인 `style={{fontSize: 숫자}}` 금지

나머지는 강제되지 않는다. radius 와 보더+그림자 동시사용과 gradient 는
`schedule.token.test.jsx` 와 `stats.token.test.jsx` 가 손으로 나열한 8개 파일에서만 본다.
굵기, 자간, 여백, 중복 컴포넌트는 어디서도 보지 않는다.

검사가 값이 아니라 문자열을 본다는 구멍이 있다.

| 막히는 것 | 통과하는 같은 값 |
|---|---|
| `text-slate-500` | `#64748B` |
| `text-[13px]` | `scaledPx(13)` |
| `style={{fontSize: 12}}` | `cssText` 안의 `font-size:12px` |

`목표` 는 검사를 값 기준으로 바꾸는 것이다. hex 리터럴, `scaledPx()`, cssText 안의 `font-size`
셋을 잡으면 지금 새는 값의 대부분이 막힌다.

`tokenRules.test.js` 의 EXEMPT 목록에 `schedule/` 세 파일이 담당 밖이라는 이유로 들어 있다.
소유자 기준 면제는 두지 않는다. 면제가 필요하면 기한과 담당을 적는다.

## 8. 현행에서 목표로 가는 매핑

- `--tj-*` semantic 토큰은 이미 sage 와 teal 기반이다. 추가 작업이 없다.
- 레거시 iDrive 계열(`bg-dark #000`, `--tj-accent-2`, navy `#1b3a6e`)은 토큰에서는 정리됐다. 코드에 `#1b3a6e` 가 여섯 곳 남아 있다.
- 폰트 굵기 800 과 900 은 `tailwind.config.js` 의 fontSize 토큰에 구워져 있다. 클래스만 바꿔서는 안 되고 토큰 값을 함께 내려야 한다.
- `head` 는 이름 충돌이 있다. 목표 스케일로 옮길 때 현재 `head`(17/700)를 `head-sm` 으로 보내고 `title`(21/800)을 `head`(21/600)로 받는다.
