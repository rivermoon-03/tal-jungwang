# 시간표 상세 표면 평면화

작성일: 2026-08-02
상태: 구현 완료

## 문제

버스 상세 시트가 정보 한 덩어리를 보여주려고 테두리를 최대 세 겹 겹쳤다.
390×844 다크 모드, 프로덕션 데이터로 실측한 값이다. "표면 겹"은 상세 시트 DOM에서
`border-radius ≥ 8px` 이면서 테두리나 배경을 가진 컨테이너 수이며, 시트 자체는 제외한다.

| 화면 | 시트 위 추가 겹 | 구성 |
|---|---:|---|
| 버스 상세 · 실시간 source | 2 | source 카드 → ETA 카드 / 통계 카드 |
| 버스 상세 · 시간표 source | 2 | source 카드 → 시각 칩 37개 |
| 버스 상세 · 여정 요약 | 1 | 내용이 중복된 카드 |
| 지하철 상세 | 0 | 시트 위에 그리드 직접 |
| 시간표 목록 카드 | 0 | 구분선으로 source 분리 |

핵심은 겹 수가 아니라 불일치다. "source별로 정보를 나눈다"는 같은 일을 목록은 구분선으로,
상세는 중첩 테두리로, 지하철은 프레임 없이 처리했다 — 한 앱에 규칙이 셋이었다.

세부 사례:

- 실시간 source 프레임은 `p-2` 패딩만 주고 아무 정보도 담지 않는다. 안쪽 ETA·통계 카드는
  이미 배경색으로 구분돼 있어 바깥 테두리가 하는 일이 없었다.
- 도착 정보가 없을 때 테두리 상자 안에 "도착 정보 없음" 상자가 또 들어갔다. 프레임이 가장
  필요 없는 순간에 가장 두꺼웠다.
- 그리드 뷰에서 프레임이 좌우 18px(테두리 2 + 패딩 16)을 먹어 칩 4열이 그만큼 좁아졌다.
- 리스트 뷰에서는 프레임이 37행을 감싸 화면 안에서 시작도 끝도 보이지 않았다. 테두리는
  경계를 알려줄 때만 값을 하는데, 위아래가 잘리면 좌우 세로줄만 남는다.
- 여정 요약 카드가 `origin → destination`과 `journey_labels`를 두 줄로 찍어, 둘이 같은
  경우 같은 문장을 두 번 읽게 했다.

## DESIGN.md 위반

| 규칙 | 근거 | 현재 코드 |
|---|---|---|
| 보더+그림자 동시 금지 | §4 · §5 네거티브 룰 | `BusEtaCard.jsx` 3곳이 `border … shadow-card` |
| radius 5토큰 밖 금지 | §4 Radius (8/10/14/20/999) | `rounded-xl`(tailwind 기본 12px), `rounded-md` |

두 파일 모두 토큰 테스트 대상이 아니었다. `*.token.test.jsx`가 `stats/`에만 있었다.

## 해결책 — B안(평면)

지하철 상세가 이미 쓰는 규칙을 버스에도 적용한다. 앱에 새 규칙이 늘지 않는다.

- source 블록의 `rounded-xl border p-2` 래퍼를 제거하고 `border-t` 구분선 + 여백으로 나눈다.
- `BusEtaCard` 세 상태 모두 프레임(보더·그림자·배경)과 좌우 패딩을 제거한다. 위계는
  숫자 크기와 여백이 세운다. 구분선의 음수 마진(`-mx-3.5`)도 상쇄할 패딩이 없어져 제거.
- `BusStatsHeader`는 카드에서 `border-t` 구분선 블록으로 바꾼다.
- 여정 요약은 프레임을 없애고, `journey_labels`가 2개 이하이거나 헤드라인과 같으면
  둘째 줄을 렌더하지 않는다.
- `rounded-xl` → `rounded-card`, `rounded-md` → `rounded-mini`.

금지 대상은 사방을 두르는 `border`(박스)다. `border-t` 같은 방향 보더는 구분선이라
B안이 오히려 쓰라고 정한 것이므로 허용한다.

## 회귀 방지

`frontend/src/components/schedule/schedule.token.test.jsx` 신설. 소스를 정규식으로 훑어
세 가지를 강제한다.

1. radius 5토큰 밖 유틸(`rounded-sm|md|lg|xl|2xl|3xl`)과 `rounded-[Npx]` 임의값 금지
2. 같은 `className` 안에 사방 보더와 `shadow-card`가 함께 오지 않을 것
3. `context.sources.map` 구간과 여정 요약에 테두리 래퍼가 없을 것

정규식은 `border(?![\w-])`로 사방 보더만 잡아 `border-t`/`border-line`은 통과시킨다.
